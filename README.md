# Backend API

Aplicação web desenvolvida para a A3 da UC de Sistemas de Comunicação e Redes.

## Sobre o projeto

Este repositório contém uma aplicação web construída com foco em front-end, utilizando **HTML**, **CSS** e **JavaScript**, com suporte adicional de **Python** e **Dockerfile** no ambiente do projeto.

O objetivo é apresentar uma solução funcional, organizada e visualmente limpa, servindo também como demonstração de habilidades em desenvolvimento web.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Python
- Docker

## Funcionalidades

- Interface web responsiva
- Estrutura organizada para facilitar manutenção
- Base preparada para evolução e melhorias futuras

## Como executar

Se o projeto for executado localmente, siga estes passos:

1. Clone o repositório:

```bash
git clone https://github.com/joap3reira36/A3-Web.git
```

2. Acesse a pasta do projeto:

```bash
cd A3-Web
```

3. Abra o arquivo principal no navegador ou execute o servidor correspondente ao seu ambiente.

Se houver uso de Docker, você também pode adaptar a execução conforme o `Dockerfile` do projeto.
